# 📌 Dungeon Busters

Dungeon Busters è un gioco di ruolo di tipo dungeon crawler con mappa esplorabile vista dall'alto: il gioco permette di scegliere un eroe (Guerriero, Mago, Ladro) e,
a partire da un villaggio iniziale, si devono esplorare e superare i 3 dungeon generati casualmente (stanze, corridoi, nebbia di guerra, minimappa),
combattendo a turni mostri e boss, raccogliendo tesori, comprando equipaggiamenti per potenziare il proprio eroe e farlo salire di livello.

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone https://github.com/thomasscarpantonio/progettoMDP_Thomas_Scarpantonio.git
```

```bash
cd progettoMDP_Thomas_Scarpantonio
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```
