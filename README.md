# 📌 Dungeon Busters

Dungeon Busters è un gioco di ruolo di tipo dungeon crawler con mappa esplorabile vista dall'alto: il gioco permette di scegliere un eroe (Guerriero, Mago, Ladro) e,
a partire da un villaggio iniziale, si devono esplorare e superare i 3 dungeon generati casualmente (stanze, corridoi, nebbia di guerra, minimappa),
combattendo a turni mostri e boss, raccogliendo tesori, comprando equipaggiamenti per potenziare il proprio eroe e farlo salire di livello.

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone https://github.com/thomasscarpantonio/progettoMDP_Thomas_Scarpantonio.git

cd progettoMDP_Thomas_Scarpantonio
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```

### ⚠️ Avviso

Si consiglia, una volta clonato il progetto, di risincronizzare gradle dal pannello verticale a destra
cliccando l'icona di gradle e successivamente sulle due frecce circolari, nel caso in cui intellij non riconosca
alcune classi che però esistono e sono senza errori; nonostante ciò il progetto compila e parte tranquillamente.

## 🤖 Uso di strumenti di AI

Per questo progetto l'AI è stata utilizzata come strumento di supporto ed aiuto in determinate situazioni,
senza mai delegarne lo sviluppo di intere parti di codice.


* Utilizzato Gemini per:

    * Capire meglio le dipendeze che dovevano avere le varie classi, cioè da quali altre dovevano dipendere
    * Suggerimenti su struttura del codice

* Utilizzato Claude per:

    * Risolvere alcuni errori di compilazione
    * Farmi aiutare nella parte di realizzazione della grafica
